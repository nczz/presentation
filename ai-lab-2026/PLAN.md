## 核心主軸

> 一個普通工程師如何靠開源社群走了十年，以及 AI Agent 時代如何讓更多人站在巨人肩膀上共好。

目標不是教技術，是**啟發**：讓學生看到開源生態的魅力，理解 AI Agent 如何降低參與門檻，進而延伸自己的興趣。

---

## 粉絲頁半年觀點提煉（融入講座素材）

### 心態面
- 「心態決定了很多事」— AI 是照妖鏡也是放大器
- 達克效應 — 剛學一點就覺得什麼都能做，碰到複雜度才知道自己不會
- 「升格管理職」衝擊 — 有了 AI Agent 等於突然多了個下屬
- 「學習 AI 走太前面，反而要學講人話」— 知道太多但無法傳達

### 開源哲學
- 「為什麼 AI 時代更要善用老牌開源軟體？」— 開源 = Protocol = AI 的韁繩（Harness）
- 「為什麼會有開源？」— 底層邏輯是商業驅動，AI 素材都是開源優先
- 「找到自己的癢就是貢獻」— 搬家工具就是這樣來的

### AI Agent 實務觀
- 工具不是越強越好，是 CP 值的平衡
- 「企業導入 AI Agent 就是一個遠端上班的數位員工」
- 知識庫必須是 Agent 內建的一部分，不是獨立工具

### 數位遷徙自由
- 軟體自由的本質是「資料儲存取用自由」
- WordPress 的 AI Client 用雲端 API → 不是「你的搜尋」→ 所以自己做 mxp-local-search

## 第一段：開源生態的魅力（50 min）

核心訊息：**門檻比你想像的低，回報比你想像的多**

| 時間 | 內容 | 手法 |
|------|------|------|
| 5 min | 破冰：「你們學資訊的，一定都很會 AI 吧？」 | 引粉絲頁貼文，引發共鳴 |
| 10 min | 我的故事：從一個搬家需求到經營社群十年 | 時間線：2014 翻譯 → 2016 Meetup → 2018 WordCamp → 2026 |
| 10 min | 開源不只是寫 code | 翻譯、報 bug、辦活動、寫文件都算。展示 WP profile badges |
| 10 min | 開源帶給我的東西 | 人脈、客戶、技術視野、公司 — 十年的複利效果 |
| 10 min | 為什麼 AI 時代更要接觸開源？ | 三個角度：素材、韁繩、門檻降低 |
| 5 min | 互動：你用過哪些開源軟體？ | 舉手互動，拉低距離感 |

---

## 第二段：從「自己的癢」開始參與（50 min）

核心訊息：**找到「自己的癢」，抓出來就是貢獻**

| 時間 | 內容 | 手法 |
|------|------|------|
| 10 min | 案例一：痞客邦搬家工具 | 自己要搬 → 寫了 → 放 WP.org → 十年後還有人用 |
| 10 min | 案例二：OwnScribe | 看到好模型 → fork 來改 → 開源 → 爆紅。重點：站在巨人肩膀上 |
| 10 min | 案例三：BrowseForge | 市場上沒有 → 自己做 → 開源 → 有人貢獻回來 |
| 10 min | 「升格管理職」心態 | 從自己寫 → 管理 AI → 管理 Agent + 社群。開源思維都通用 |
| 10 min | 怎麼找到第一個貢獻？ | good first issue / 翻譯 / 文件 / 報 bug / 按 Star |

---

## 第三段：實作 — AI Agent 做 WP 外掛（80 min）

核心訊息：**AI 降低了技術門檻，「做什麼」比「怎麼做」更重要**

| 時間 | 內容 | 手法 |
|------|------|------|
| 10 min | AI Agent 是什麼感覺？ | 開場 demo，解釋「導演 vs 劇組」比喻 |
| 10 min | 需求發想 | 互動：選一個功能來做。備選：金句/閱讀時間/打招呼 |
| 40 min | Live Coding | 全程 AI Agent 操作，邊做邊解釋指令思路和修正過程 |
| 10 min | 部署上線 | 用 WordPress Playground 即時載入展示 |
| 10 min | 從 side project 到開源 | GitHub repo + README + LICENSE → Push → 你是貢獻者了 |

### 備選 Demo 主題

| 方案 | 適合情境 | 複雜度 |
|------|---------|--------|
| A：每日金句短碼外掛 | 最簡單，完全不懂 code 的場 | ⭐ |
| B：文章閱讀時間估算 | 中等，展示實用性 | ⭐⭐ |
| C：訪客打招呼訊息 | 有前端互動效果 | ⭐⭐ |
| D：現場學生提議 | 最有參與感 | 看情況 |

如果現場沒人回應，用方案 B 保底（最直觀、好 demo、好解釋）。

## 學生帶走的東西

1. **WordPress Playground** — 零成本立刻能玩：playground.wordpress.net
2. **推薦資源連結** — GitHub nczz、Gist 教學集、粉絲頁
3. **「如何開始參與開源」行動清單**：
   - 打開 WP Playground 玩玩
   - 找一個有趣的 GitHub 專案按 Star
   - 搜尋 `good first issue` + 你會的語言
   - 加入一個開源社群
   - 裝一個 AI Agent 工具試試
4. **今天 live demo 的外掛原始碼** — 放 GitHub 讓他們 fork
