## 課程三段結構

### 第一段：開源生態的魅力（50 min）13:15–14:05

核心訊息：門檻比你想像的低，回報比你想像的多

1. 破冰：「你們學資訊的，一定都很會 AI 吧？」
2. 我的故事：翻譯一個字串 → 辦 Meetup → 辦 WordCamp → 開公司
3. 開源不只是寫 code：翻譯、報 bug、辦活動、寫文件
4. 開源帶給我的：人脈、客戶、技術視野、公司
5. AI 時代更要開源：AI 的素材是開源、開源 = Protocol = AI 的韁繩
6. 互動：你用過哪些開源軟體？

### 第二段：從「自己的癢」開始參與（50 min）14:05–14:55

核心訊息：找到「自己的癢」，抓出來就是貢獻

1. 案例：痞客邦搬家工具 — 自己要搬 → 寫工具 → 開源 → 幫到上百人
2. 案例：OwnScribe — 看到好模型 → fork 來改 → 開源 → 意外爆紅
3. 案例：BrowseForge — 市場上沒有好方案 → 自己做 → 開源
4. 「升格管理職」心態 — 從自己寫到管理 AI Agent 幫你寫
5. 怎麼找到第一個貢獻？— good first issue / 翻譯 / 文件 / 從你用的工具開始

### 中場休息（15 min）14:55–15:10

### 第三段：實作 — 用 AI Agent 現場做一個 WP 外掛（80 min）15:10–16:30

核心訊息：AI 降低了技術門檻，「做什麼」比「怎麼做」更重要

1. AI Agent 是什麼感覺？（開場 Demo）
2. 需求發想：跟學生互動決定做什麼功能
3. Live Coding：全程用 AI Agent，講解「為什麼這樣下指令」
4. 部署：WordPress Playground 即時載入
5. 開源上架：GitHub README + License = 你是開源貢獻者了

### 收尾：共好（15 min）16:30–16:45

1. 今天的旅程回顧
2. 站在巨人肩膀上共好
3. 行動呼籲 + 資源分享

## 設計原則

- 不技術面，講心態和故事
- 用自己的真實經歷當案例
- 互動 > 單向輸出
- 學生帶走的是「啟發」和「方向感」
- 第三段 live demo 有帶設備的跟著做，沒帶的看操作理解思路
