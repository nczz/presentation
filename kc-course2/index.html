Part 2

Obsidian 版本

Skills 驅動的第二大腦

Obsidian + AI Agent

一個 Prompt 完成安裝、啟用 Skills、初始化 Vault

「幫我研究 obsidian-second-brain 開源專案並安裝啟用 Skills 與初始化」


建議啟用外掛：

  • Bases
  • Dataview
  • Templater
  • Kanban
  • Calendar

情境 1

開完會把重點存進 Vault

$obsidian-save

「跟張經理開會，他決定用 PostgreSQL 取代 MySQL，預算上限 50 萬，下周三前要出 POC。」


Agent 自動：

  • 建立/更新 People note
  • 記到 Project Key Decisions
  • 加 Kanban Task
  • 更新 Daily Note

情境 2

研究一個技術主題

$research

$research "Cloudflare Durable Objects vs Redis for real-time state"


Agent 自動：

  • 從多來源蒐集資料
  • 寫 AI-first 研究筆記
  • 每個 claim 標注來源和時間戳

情境 3

每天早上看今天該做什麼

$obsidian-daily


  • 建立/更新 Daily Note
  • 拉進 Kanban 到期任務
  • 加入昨天 carry-over 項目

情境 4

挑戰自己的想法

$obsidian-challenge

「我想把 backend 從 Node.js 改寫成 Go」


Agent 從 vault 歷史找出：

  • 類似決策
  • 失敗經驗
  • 矛盾紀錄

→ 用你自己的筆記反問你

情境 5

吸收一個 YouTube 影片

$youtube


流程：

  1. 抓 transcript
  2. Gemini / Grok 摘要
  3. 存成 AI-first 筆記
  4. 自動 cross-link

情境 6

看最近一周做了什麼

$obsidian-recap week


讀取：

  • 7 天 Daily Notes
  • Dev Logs
  • 完成的 Kanban 項目

→ 結構化週回顧摘要

情境 7

Vault 健康檢查

$obsidian-health


掃描找出：

  • 壞連結
  • 重複筆記
  • 過期 Claims
  • 孤立筆記
  • 前後矛盾

如何建立一個 Skill？

高鐵票查詢案例


Skill = 一份 Markdown 說明書


  • name — 技能名稱
  • description — 觸發條件描述
  • 觸發條件 — 什麼情境啟用
  • API 端點 — 實際操作方式
